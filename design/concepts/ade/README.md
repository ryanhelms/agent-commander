# Agent Development Environment concepts

The [project cockpit](01-project-cockpit.png) is the default workspace. The explorer opens projects and runs and identifies each worker by its parent, host, and worktree. The coordinator stays visible when the document area switches between the wall and review. Collapse secondary regions before narrowing the consoles.

The [change review](02-change-review.png) turns the existing worker handoff and integration operation into a review surface. Lead with committed revisions, findings, combined test output, and the recorded target branch. The generated file tree, styled diff, and individual test hierarchy show a possible extension. The first implementation can use the existing handoff and integration records.

The [focused intervention](03-focused-intervention.png) uses the same console in a larger workspace. The floating request belongs to another worker. Its identity, draft, and delivery state follow it across PiP and the pinned sidebar. Answering it leaves the focused worker’s input ownership in place.

Keep the current square console frame, black glass application chrome, semantic terminal color, and existing keyboard actions. Keep the right sidebar as the default request presentation. Preserve worker zoom, nested grouping, and the draggable coordinator split. Render loading, missing capabilities, reconnecting, and disconnected states from existing presentation contracts. Use the existing transcript and ACP inspector across views. The generated progress bar, prefilled reply, and demonstration file hierarchy are illustrative.
